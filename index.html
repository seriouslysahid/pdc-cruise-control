Section 2
All 11 Tasks — Step by Step
Follow exactly. Every equation, every variable, every educational note — laid out for maximum clarity.
1

Process Description & Schematic

CV: Vehicle speed v (m/s)
MV: Engine force u (N)
Disturbances: θ, wind, payload

Schematic: Free-body diagram showing m, u (engine force), −bv (drag), −mg sin θ (gravity). Block diagram: Setpoint → PID → Plant → Speed (feedback loop) + disturbance input.

📚 Cruise control is a regulatory + servo problem — maintains speed (regulatory) while allowing driver to change setpoint (servo).
2

Model Development — Force Balance (Newton's 2nd Law)

Nonlinear model with quadratic drag for realism:

m dv/dt = u − bv − cv² − mg sin(θ)
m = 1500 kg
b = 50 Ns/m
c = 0.5
g = 9.81 m/s²

Steady-state operating point: vs = 20 m/s (72 km/h), θs = 0, solve for us.

🔬 Derivation: Sum of forces = ma. Engine force (MV) overcomes drag + gravity.
3

Linearization — Around Steady-State

Deviation variables: v' = v − vs, u' = u − us, θ' = θ

Linearized (first-order Taylor):

m dv'/dt = −(b + 2cvs)v' + u' − mg cos(θs)θ'

Simplified (θs = 0):

dv'/dt = −a·v' + b·u' − d·θ'

where a, b, d are constants you calculate from the parameters.

⚠️ Linearization ignores higher-order terms — valid only near the operating point.
4

Transfer Function (SISO for Speed)

Laplace transform (ignoring disturbance first):

Gp(s) = V'(s)/U'(s) = K / (τs + 1)
K = 1 / (b + 2cvs)
τ = m / (b + 2cvs) ≈ 20-30s

Separate disturbance TF:

Gd(s) = −mg cos(θs) / (ms + (b + 2cvs))
📐 System order: 1 (basic) — easy to analyze.
5

Dynamic Analysis

  • Gain K: Steady-state speed change per unit throttle.
  • Time constant τ: Speed of response.
  • Open-loop: Sluggish, no oscillation, approaches new speed asymptotically.
6

Controller Design — P, PI, PID

PID form in time domain:

u(t) = Kc[ e(t) + (1/τI)∫e(t)dt + τD de(t)/dt ], e = vsp − v
  • P: Fast but has steady-state offset.
  • PI: Zero offset — best for constant disturbances like mild hills.
  • PID: Fastest but sensitive to noise (speed sensor).
🏆 Most suitable: PI — industry standard for cruise control.
7

Controller Tuning — 2 Methods

1. IMC (Recommended — Robust):

Kc = (τ + λ) / (Kλ), τI = τ + λ, λ = max(0.2τ, dead-time)

2. Ziegler-Nichols Reaction Curve: From open-loop step response → fit FOPDT → apply rules.

Tabulate gains for P, PI, PID using both methods.

8

Simulation — Core Python Work

  • Nonlinear closed-loop: scipy.integrate.odeint on full nonlinear ODE + discrete PID.
  • Linear validation: control.TransferFunction + feedback.
  • Setpoint step: 20 → 30 m/s at t=0.
  • Time: 0–200 s, dt = 0.1 s.
9

Performance Comparison

Metrics table (use pandas):

  • Rise time (10–90%)
  • Overshoot (%)
  • Settling time (±2%)
  • IAE / ISE
📊 Expected: P has offset; PI eliminates offset cleanly; PID slightly faster but noisier.
10

Disturbance Analysis

At t = 100 s: sudden road grade θ = +5° (hill).

PI/PID reject it best — minimal speed dip, fast recovery.

11

Discussion & Recommendation

  • Model captures real physics.
  • Linearization good near 20 m/s.
  • Recommendation: PI controller (IMC-tuned) — robust, zero offset, simple.
  • Limitations: Sensor noise, actuator saturation, nonlinear drag at high speed.
